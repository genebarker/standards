# Primary Actors

This document defines the primary actors of the system.

The section heading represents the full Business User name (e.g., "Compliance
Officer"), while the Shortname represents the code (e.g., "`C`ompliance") used
to map the actor to access control lists (ACLs) and security rules.

## Payroll Manager

Shortname: `M`anager

The Payroll Manager supervises the payroll operations and assists Payroll
Officers. The Payroll Manager uses the system to monitor system performance,
verify payroll activity, and audit the financial summaries.

## Payroll Officer

Shortname: `O`fficer

The core user of the payroll system is the Payroll Officer. The Payroll Officer
processes employee timecards, generates payruns, and manages direct deposit
information.

## Executive

Shortname: `E`xecutive

An Executive is a senior user that needs high-level view-only access to payroll
summaries, financial reports, and system analytics.
